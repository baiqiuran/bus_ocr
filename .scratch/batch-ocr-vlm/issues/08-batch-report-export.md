# 08: 批量报告 + 导出

**What to build:** 为每个批次生成可读报告，汇总完成数、失败数、复核数、阶段耗时、缓存命中、OCR/VLM 调用和失败原因；导出的每张海报 JSON 可以继续交给现有分析器生成 Excel、CSV 和报告。

**Blocked by:** 02（批量 manifest + 单海报全链路）

**Status:** done

- [x] 批次报告包含总数、done/failed/pending 数量、复核数量、总耗时和各阶段耗时
- [x] 报告包含缓存命中率、OCR 调用数、远程重试数、fallback 数和 VLM 调用数
- [x] 失败项在报告中带错误原因和重试次数
- [x] fixture 批次的输出可以直接交给现有分析路径，生成站点明细和线路汇总
- [x] 断点续跑后报告能正确反映最终状态，不重复计数
- [x] 不要求用户手工合并每张海报的 JSON
