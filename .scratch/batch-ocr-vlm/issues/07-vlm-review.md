# 07: VLM 复核 + 防静默覆盖

**What to build:** 对复核队列中的异常裁片调用视觉模型，提供目标裁片、前后站、线路、表头下站和开往方向作为上下文；VLM 只返回结构化意见，不得静默覆盖 OCR 最终值。

**Blocked by:** 06（复核队列 + 来源与人工覆盖）

**Status:** done

- [x] 只有被标记的异常裁片会调用 VLM，正常项不产生 VLM 请求
- [x] VLM 返回非法 JSON、空结果或低置信度时被忽略，不影响主数据
- [x] OCR 与 VLM 一致时自动清除对应异常标记
- [x] OCR 与 VLM 不一致时保留两份结果并进入人工复核
- [x] OCR 为空时 VLM 结果可作为候选，但必须标记为 VLM-only 并进入复核
- [x] 每张海报的 VLM 调用数受配置上限约束
- [x] VLM 结果按裁片、提示词版本和模型版本缓存，重复运行不重复调用
