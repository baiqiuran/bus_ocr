# 03: 断点续跑 + 海报/块级缓存

**What to build:** 让批处理在任意阶段中断后都能从已完成的海报或路线块继续；缓存按图片哈希和版本隔离，坏缓存或配置变化时自动重跑。

**Blocked by:** 02（批量 manifest + 单海报全链路）

**Status:** done

- [x] 在一个路线块完成后终止进程，重新运行只处理未完成块，已完成块不重新 OCR
- [x] 海报级缓存命中时完全不调用 OCR，并返回与首次运行一致的结构化结果
- [x] 修改打包参数、OCR 参数或管线版本后，旧缓存失效并触发重跑
- [x] 人为破坏缓存内容后，系统忽略该缓存、重新识别并写回有效结果
- [x] 并发 worker 同时写同一缓存时，不产生部分文件或损坏结果
