# 05: 远程 OCR + 限流/重试/回退

**What to build:** 增加远程 OCR 适配器，本地负责切块，远程只接收画布并返回文字、坐标和置信度；支持一个请求携带多个画布，以及超时、429、5xx、熔断和本地回退。

**Blocked by:** 04（OCR backend + 动态画布）

**Status:** done

- [x] 用 fake OCR 服务跑通同一批 fixture，最终结果与本地后端一致
- [x] 一个 HTTP 请求可携带多个画布，远程请求数明显少于逐画布请求数
- [x] 远程超时或连续 5xx 时按策略重试，仍失败则回退本地 OCR，海报最终完成
- [x] 429 响应触发退避，不形成重试风暴
- [x] 记录远程请求数、延迟、重试数、fallback 数和失败原因
- [x] 地址、模型名和密钥从配置或环境读取，密钥不写入日志和输出
