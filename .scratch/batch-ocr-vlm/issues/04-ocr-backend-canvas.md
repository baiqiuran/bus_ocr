# 04: OCR backend + 动态画布

**What to build:** 把 OCR 推理收敛到统一后端接口，本地 RapidOCR 作为首个适配器；画布按真实列宽和列数动态打包，站名与备注尽量同组，批量识别异常时自动回退单列。

**Blocked by:** 02（批量 manifest + 单海报全链路）

**Status:** done

- [x] 同一张 fixture 海报通过 OCR 后端处理，站名、备注和站序与现有基线一致
- [x] 画布打包遵守最大列数、最大宽度和列间距，不再固定八列
- [x] 站名与紧随其后的备注列不会被拆到不同画布
- [x] 检测框跨列、覆盖不足或结果为空时触发单列 fallback
- [x] 修改最大列数或最大宽度会改变画布数量，但不改变最终站名结果
- [x] 打包规则、备注分组和 fallback 均有自动化测试
