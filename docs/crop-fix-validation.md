# 2.4.1 裁切修复验证

本次修复红色外框误入端点裁片，以及同批样本中的站名行截断、红色横条和广告干扰。范围仍为 [精简模式](endpoints-mode.md)，没有增加完整途经站序提取。

## 实现

- 站名列检测检查行内及上下文的红色覆盖。持续跨过文字行、接近实心的红色纵条作为背景排除；真实红色站名保留。没有把右边界统一缩为 `4000`。
- 精简模式的行投影先排除整行红色背景/横条。若黑字跨过初始搜索边界，只延续当前连续文字段，保持原阈值，不重新选择下方更密集的广告；范围仍受下一版块限制。
- 精简模式只合并相邻片段。完整模式继续使用原行搜索、合并策略；原安平小区几何基准保持一致。
- `PipelineSettings.pipeline_version` 升为 `2.4.1`，使新处理的缓存键区别于旧版本。已完成 manifest 不会因此自动重跑，验证使用独立输出目录。
