# 线路号定位失败后的恢复与跳过分类

这条分支只用于 `endpoints`，并且只在原有线路号定位抛出异常、图片尺寸匹配 `buspipe/templates.py` 的 `RECOVERY_PROFILES` 时触发。原定位成功的图片继续使用原设置、坐标、OCR 裁片和解析路径；`full` 与横版原分支不进入这里。

## 失败回退的边界

`PROFILES` 仍负责原模板设置。新增的 `RECOVERY_PROFILES` 同样使用 `TemplateProfile`，按精确尺寸登记小字号、大字号和红框模板；它不替换原分支。其 `name:version` 进入对应图片的 endpoints 批处理缓存 key。未匹配的模板和 full 模式保持原 key。修改恢复比例或算法时必须提升对应恢复 profile 的 version，并用新输出目录验收。

恢复过程先测量长红色边框内侧，在线路号投影时剔除边框，再使用本族的字号范围。候选还需满足独立字形的连续高度要求，避免降低阈值后把竖排当前站名当成线路号。不得直接放宽全局 LayoutSettings。

恢复后的站名行按垂直列形状、跨度和顺序定位，跳过横线、方形二维码和页脚。白字彩底与绿色字使用单独的几何视图，OCR 始终使用原图裁片。几何坐标缩放后转换回原图；不从中间站替代读不清的端点。

每条恢复记录写入 `recovery_profile`，生成 `recovered_layout` 复核项。找到候选块不代表线路号和首末站正确。乱码保留原文，异常字符进入 `suspicious_text` 复核，不自动猜测或改写。

## 无线路信息的图片

同样仅在原定位失败后判断。程序不使用文件名独自断定图片应跳过：

| board_type | 判定证据 |
| --- | --- |
| `blank` | 去除边框和页脚后，白色内容区没有文字 |
| `inactive` | 内容区无正常站序黑字，OCR 明确识别出“本站未启用”或“本站暂停使用” |
| `notice` | 已登记的通知文件名族，并且图中明确识别出“公交保障” |
| `wayfinding` | 车道指示文件名族，同时符合蓝底白字、几乎无红字的版式 |

标题置信度仅统计实际覆盖匹配标题的 OCR 项，不把孤立的下划线、数字或“一”字噪声当作标题置信度。分类版本 `classification2` 也进入缓存 key。没有明确证据时保留失败，不用宽松关键词猜测分类。

被确认的图片保存独立原始 JSON，含 `skipped=true`、`board_type`、`skip_reason` 和分类依据，manifest 状态为 `skipped`。报告单列跳过数及清单；不计为 `done`、`failed` 或 `incomplete`，不输出虚假的空线路记录。跳过状态是自动流水线终态，再次运行同一 manifest 不重复识别。

## 验收

回归入口为 `tests/test_route_recovery.py`。覆盖红框与真实红字分离、大小字号、旧分支成功时禁止进入恢复、未知模板、空白/未启用分类、真实线路不误跳过、跳过后断点续跑、白字彩底、二维码排除与乱码复核。

本次真实对照固定了旧版 `9504593` 的代码和 6309 张历史 done 图片清单；重新运行选中的 20 张横竖版控制图，新旧均为 16 张完成、4 张原有端点失败，57 条导出记录及完成图片的原始 JSON 一致。历史 done 清单不等于人工正确率；这次 A/B 也不代表已重新验证全部 6309 张。

本机证据目录为 `output/unlocated-fix-validation-20261027/`：`ab_comparison.json`、`ab-before/`、`ab-after/` 保留新旧对照。最终交付在 `final/`，来自 `release-1/`、`release-2/`、`release-3/` 三个不重叠子集；全部 131 张使用同一份冻结代码重新处理，每张只处理一次。`release_code_fingerprint.json` 和 `release-source.zip` 固定这份代码，`validation_sources.csv` 保留逐图来源。各目录独立 manifest，不覆盖此前批次。

2961×3912 的黄色 357 路为上下拼接的正反两面，单独登记 `route_recovery_stacked:1`，按各面版式提取并保留两个 block_index。它不进入普通竖版列定位。调试阶段的 `acceptance/`、`special-v2/` 等保留问题复现与对照，最终数据不从这些不同阶段拼接。

大字号火车站族使用 `route_recovery_large:3`，仅在该族增加站名首字、末字与其余字的合并间距，避免把单字行当作完整站名行。其他恢复族保持原合并间距。彩底几何视图同时保留白字、黑字和红色当前站名；不能在去除背景时抹去位于端点的红字，误取旁边的中间站。

4726×7678 另登记 `route_recovery_4726:2`：同一尺寸中存在字号更小的站牌，因此恢复最小字高使用该族的比例，并保留独立字形连续性检查。小字号和普通红框恢复族也因彩底红字规则升级至 version 2。原本能定位成功的同尺寸图片仍走旧分支。

提取范围仍是当前站名、文件名方位、线路号和有序首末站，`stops=[]`；不补全途经站点。
